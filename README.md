# 🧮 Java · Algoritmos fundamentales

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white)

Colección de algoritmos clásicos implementados en Java puro, como base de la lógica de programación: decisiones, ciclos, recorrido de cadenas y reutilización de métodos.

> Ejercicio del **Bootcamp Full Stack Java (2026)**.

## ✨ Algoritmos incluidos

| Método | Qué resuelve |
|---|---|
| `esPar(int)` | Determina si un número es par usando el operador módulo |
| `esPrimo(int)` | Cuenta los divisores de un número para saber si es primo |
| `stringEnReversa(String)` | Invierte una cadena recorriéndola de atrás hacia adelante |
| `esPalindromo(String)` | Reutiliza la inversión para detectar palíndromos (sin distinguir mayúsculas) |
| `secuenciaFizzBuzz(int)` | Imprime la secuencia FizzBuzz hasta el número indicado |

## 📁 Estructura

```
src/
├── Aplicacion.java        ← punto de entrada con ejemplos de uso
└── clases/
    └── Algoritmos.java    ← métodos estáticos con cada algoritmo
```

## ▶️ Cómo ejecutarlo

Requisitos: JDK 17 o superior.

```bash
git clone https://github.com/evelyntec/java-algoritmos-fundamentos.git
cd java-algoritmos-fundamentos/src
javac Aplicacion.java clases/Algoritmos.java
java Aplicacion
```
